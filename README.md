# E-Commerce Sales Data Analysis

## Overview

This project analyzes 54,190 e-commerce transaction records using Microsoft Excel.

## Objective

Identify top-selling products and derive business insights from sales data.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts

## Analysis Performed

### Top Selling Products

* Grouped products by description.
* Calculated total quantity sold.
* Identified Top 10 best-selling products.

### Country-wise Sales Analysis

* Analyzed sales distribution across countries.
* Ranked countries based on sales volume.

## Key Findings

* A small number of products contributed significantly to total sales volume.
* Sales were concentrated in a few major markets.
* Product-level analysis can support inventory planning and demand forecasting.

## Dataset Size

54,190 transaction records.
